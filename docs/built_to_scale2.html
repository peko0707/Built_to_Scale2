Built to Scale 2 ゲームガイド

ゲーム内容

Built to Scale 2 は、BGMに合わせて左右から近づく一対のブロックを、中央でタイミングよく消すリズムゲームです。MISS数を少なくして高い結果を目指します。

遊び方

  1. 任意のキーを押す、またはゲーム画面をクリックして開始します。
  2. 左右のブロックが中央に重なるタイミングで、任意のキーまたはクリックで入力します。
  3. タイミングが正確なら Perfect!、ずれていると Miss! になります。
入力しなかったブロックもMISSになります。BGM終了後に結果が表示されます。

結果ランク

MISS数結果
0〜3HIGH LEVEL
4〜15GOOD
16以上REDO

記録

プレイ終了時のMISS数が保存され、最少MISS数が自己ベストとして表示されます。
